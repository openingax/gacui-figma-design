# DatePicker 弹板

当前目标集合71:126已补齐六种用途：年份、月份、日期、日期时间、日期区间、日期时间区间。生成、内容修改与完整用法统一使用[DatePicker家族](../datepicker/README.md)的generator.mjs。

本目录build-data.json及source.raw.json保留最初单日期模板的精确证据，供共用头部和星期文字取值；不再作为完整家族的构建入口。当前target.json只保存仍有效的主组件映射；target-initial.json为历史对照，旧内部节点不可继续操作。

六类弹板与输入的组合已实测，临时字体与浮点差异如实记录。没有用户验收，不加✅；静态可编辑设计不是交互原型。
