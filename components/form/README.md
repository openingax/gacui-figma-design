# Form 表单

V1.6.0提供当前静态字段、校验反馈和布局，以及工作台/抽屉完整组合。当前源覆盖与真实验证见[发行说明](../../docs/form-release.md)。

通过sketch规划并确认草稿，再运行portable计划、初始化依赖及按真实回执生成。新文件不可直接使用旧target IDs；低层legacy generate保留目标门禁。现行范围包括11类顶部控件、7种校验反馈、8基础字段、4提示状态及34布局；日期区间是输入组合。密码只显示遮罩，不提供明文浏览；独立控件全家族不由Form字段外观推断。

已有字段编辑先保存captureFieldSnapshot并显式提供当前范围的保护集合，使用fitFieldContent；失败保留原错误并回报自动恢复是否成功。恢复用restoreFieldSnapshot并独立capture对照。外置标签首次本地化会改变ID，不能承诺detach身份自动回滚。新建失败只移除本次容器。

长标题/说明换行并增高；固有窄控件默认保留宽度。controlWidth仅支持与字段同宽或省略；不支持的宽度在任何setter之前拒绝。必填、说明、校验和控件禁用互不替代。Form内上传旧稳定路径可用，上传原位说明扩展另批完成。

产物为可编辑静态设计；业务提交、真实日历/时间交互及桌面苹方和用户验收需具体任务确认。云端Noto仅为临时替代。
