# Link 链接

源组件集 `69043:216869` 共 32 个变体：大/中两种尺寸，前图标、后图标、双图标、无图标四种槽位，默认/悬停/点击三种状态，外加每种槽位只在默认态出现的禁用。规范没有禁用与悬停或点击的组合，生成器会拒绝这种输入。

调用 `renderLink(figma, parent, spec)`。参数：`id`、`size: large|medium`、`state: normal|hover|active`、`disabled`、`prefix`、`suffix`、`text`、`prefixIcon`、`suffixIcon`。后两个只接受 `link` 或 `jump`，并且对应槽位必须可见。默认是中尺寸、默认态、无图标、文案“跳转链接”。

目标组件集暴露文字属性 `text 文案`，以及前置 `prefixIcon instance 前置图标实例`、后置 `suffixIcon Instance` 两个实例交换。交换后的颜色不会跟着原图标覆盖自动迁移，`updateLink` 会按当前状态重新套用品牌色。更换尺寸、状态或图标槽位需要换变体，不能原位改。

源里两处 medium active 前置图层名叫 download（`69046:217052`、`22709:34677`）。它们的主组件仍是 link `75:2123`，路径与 link 相同，只是点击色。这不是第四种图标。活跃示例没有改文案，也没有换成别的图标。

表格里已有的“Link 链接”实例不属于这个组件集，不能据此说表格操作已经覆盖本家族。草稿已支持独立 `link` 节点，工作台和抽屉可用，支持文字、尺寸、状态、禁用、图标槽位和图标交换的状态补丁。
