# 表单编辑范围与失败处理

V1.3.3 是现有字段编辑的宽度预检补丁，不是 Form 家族全量导入版。

原位编辑时，实例控件只接受与字段同宽的显式 `controlWidth`；省略该项继续保留原有控件源宽策略。不支持的显式宽度现在会在查找源组件、加载字体、detach 和 resize 之前报错，避免该类错误造成部分改动。此预检不承诺其他错误都能自动回滚。

Upload 原位修改标题、说明及必填标识仍属于未完成扩展，不使用通用同名文本查找来替换上传说明：附件文件名也可能叫 `tips`。这不取消 1.3.2 已有的抽屉上传出稿能力。

单字段的长内容、选中状态保持或恢复通过，不等于整个 Form 家族、所有禁用/错误态、弹层交互或用户页面验收通过。后续交互与未覆盖状态仍须逐项验证。

Figma 发生错误或返回内容超限时，先独立回读；不能仅凭错误响应断言画布未改动。需要恢复时依据真实写前快照执行，恢复后再次检查目标与保护节点。没有原始证据时明确标注未知，不编造成功回执。

升级保留草稿、本地配置、固定版本与日志关闭偏好；不自动开启日志或安装 hooks。已发布版本以正式标签和 Release 为准。
