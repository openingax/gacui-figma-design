字段标签、控件、反馈和操作区共享同一排版规则。已有内容使用写前完整快照恢复，新建失败清理本次根。外置标签首次detach不能恢复原身份，必须采用返回ID；不把这一边界包装为全故障点回滚支持。

发行包附带固定版本的纯JS代码压缩器UglifyJS3.19.3（BSD-2-Clause，许可证随包），只在代码接近工具上限时压缩传输。Form预编译依赖带源函数哈希校验，普通使用无需npm或平台构建器。

独立Upload及其原位内容编辑扩展下一批完成；既有表单/抽屉上传不变。Form字段不代表Radio/DatePicker等独立家族全覆盖。源文件只读，写入目标需当前授权，保护集合从当前实际目标确定。桌面字体、运行时业务交互与UI验收分别记录。
