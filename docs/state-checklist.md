# 边界状态清单

日期：2026-10-13。版本 v0.1（2026-10-15 校正组件支持说明，业务默认不变）。用途：AI 整理需求、编写方案卡（内部验证资料未随公开包分发）时逐项检查，把“需求里没写但必须决定”的点变成给产品经理的选择题。本清单不是业务规则；推荐默认值只是提问时的建议选项，最终以产品经理的回答为准。

## 使用方法

1. 按页面里实际出现的模式（列表、表单、上传等）选取对应小节，不用的小节跳过。
2. 每一项判断：需求原文已写明 → 记为“已明确”并注明出处；没写 → 列为“待产品决策”，附推荐默认值；本轮不做 → 记为“本轮不做”。
3. 每次最多集中问一批问题，产品经理可以回复“按推荐”。回答后写回方案卡，不在聊天里散落。
4. 不把源规范的样例数量、样例文字、默认选中当作业务规则；不用相似控件冒充缺失组件。

依据标记：**规范**＝组件规范或已导入组件的事实（见对应组件 README）；**试用**＝2026-10-13 工单试用中用户确认的规则，仅作推荐，不自动适用于其他业务；**判断**＝设计判断，必须经产品经理确认；**缺口**＝组件库目前没有对应组件。

## L 列表与查询页（Search / Table / Pagination）

| 编号 | 要决定的事 | 问产品的方式 | 推荐默认 | 依据 |
|---|---|---|---|---|
| L1 | 查询条件何时生效 | 修改条件后是点“查询”才生效，还是立即生效？ | 点“查询”才生效 | 试用 |
| L2 | 查询后的分页与选择 | 每次查询是否回到第 1 页并清空已选行？ | 是 | 试用 |
| L3 | 重置的结果 | “重置”是否立即恢复全部数据、清空文本条件、下拉回到“全部”？ | 是 | 试用 |
| L4 | 筛选无结果 | 没有匹配数据时显示什么文案？是否提供“重置筛选”入口？ | “暂无符合条件的XX”＋“重置筛选” | 试用；compact空态已有草稿入口，其他类型仍须核对组件目录；需 UI 确认 |
| L5 | 首次就没有数据 | 列表本身为空（不是筛选导致）时，文案和引导是否不同（例如引导创建）？ | 与 L4 区分，文案说明“暂无XX”，有创建权限时给创建入口 | 判断 |
| L6 | 加载中 | 列表加载时是否需要单独的状态稿？ | 本轮不做，除非产品要求 | 判断；表格加载组件为**缺口** |
| L7 | 加载失败 | 数据加载失败时如何提示、能否重试？ | 本轮不做，除非产品要求 | 判断 |
| L8 | 分页 | 每页条数？是否允许切换条数、跳转？总数是否显示？ | 每页 10 条，显示总数 | 试用；Pagination 有基础/总数/条数选择/跳转/极简五类，**规范** |
| L9 | 长内容 | 哪些列可能很长（编号、名称、地址）？超长时单行省略是否可以接受？ | 单行省略，列宽按内容类型设定 | **规范**（Table 已验证长文字截断） |
| L10 | 多选与批量操作 | 是否需要勾选？全选只选当前页还是全部数据？没选时批量按钮是否禁用？ | 只选当前页；没选时批量禁用 | 试用 |
| L11 | 不可选择的行 | 是否有不能被勾选的行？ | 本轮不做 | 业务组合已接通禁选行及Checkbox禁用态；源属性矛盾仍保留，不自动成为新业务规则 |
| L12 | 行操作随状态变化 | 每种数据状态下各显示哪些操作？超过 3 个时哪些收进“更多”？ | 按状态逐一列出 | **规范**（每行 0–3 个文字操作＋“更多”） |
| L13 | 无权限的操作 | 没有权限时操作是隐藏还是置灰？ | 隐藏 | 判断 |
| L14 | 列很多 | 列放不下时是横向滚动、列设置还是删减列？ | 先删减到主要列，其余进详情 | 判断 |
| L15 | 操作后的列表 | 新建、删除、状态变化后，列表停在当前页还是回第 1 页？新记录放在哪里？ | 新建后回第 1 页、新记录置顶 | 试用 |

## F 表单、抽屉与弹窗（Form / Drawer）

| 编号 | 要决定的事 | 问产品的方式 | 推荐默认 | 依据 |
|---|---|---|---|---|
| F1 | 容器 | 用页面、抽屉还是弹窗承载？ | 字段多于 6 个用抽屉；确认类用弹窗 | 判断；基础双按钮确认弹窗已部分支持，其他变体仍为**缺口** |
| F2 | 抽屉尺寸 | 内容是否放得下规范的 300 / 500 / 760 宽？ | 选能放下内容的最小规范尺寸 | **规范**；试用沿用既有稿 900 宽，属于历史稿例外 |
| F3 | 初始值 | 每个字段打开时是空的还是有默认值？下拉默认哪一项？ | 逐字段列出，不默认选中样例值 | 试用 |
| F4 | 必填项 | 哪些字段必填？只输入空格算不算填了？ | 去掉首尾空格后判空 | 试用 |
| F5 | 字数上限 | 文本字段最多多少字？是否显示计数？ | 有上限的字段显示“当前/上限” | 试用 |
| F6 | 校验时机 | 点“确定”时统一校验，还是填写时就校验？ | 点“确定”时统一校验 | 试用 |
| F7 | 错误展示 | 错误是显示在字段下方，还是集中提示？出错后已填内容是否保留？ | 字段下方就地提示，保留已填内容 | 试用；Form 校验字段有 7 种状态，**规范** |
| F8 | 字段联动 | 是否有级联或联动（选了 A 才能选 B、选项随前项变化、某选项展开新字段）？ | 逐个确认；未确认的展开态本轮不做 | 判断 |
| F9 | 提交中 | 是否需要表达“提交中”（按钮加载、禁止重复提交）？ | 本轮只做说明 | Button Loading 静态外观已有，**规范** |
| F10 | 提交成功 | 成功后关闭吗？如何提示？列表如何变化（见 L15）？ | 关闭并提示成功 | 试用；全局提示组件为**缺口** |
| F11 | 提交失败 | 服务失败时如何提示？内容是否保留？ | 本轮不做，除非产品要求 | 判断 |
| F12 | 关闭与取消 | 关闭/取消是否丢弃已填内容？有内容时是否二次确认？点蒙层是否关闭？ | 直接丢弃、不二次确认、点蒙层不关闭 | 试用 |
| F13 | 长内容 | 长标题、长段落时底栏是否固定、内容区是否滚动？ | 底栏固定，内容区滚动 | 试用 |
| F14 | 标题过长 | 抽屉标题超出可用宽度时怎么办？ | 缩短文案（规范未定义省略方式） | **规范**（构建时只给警告，不自动省略） |
| F15 | 底栏按钮顺序 | — 不问，按规范 | 左对齐：确定→取消；右对齐：取消→确定 | **规范** |

## U 上传（Upload）

| 编号 | 要决定的事 | 问产品的方式 | 推荐默认 | 依据 |
|---|---|---|---|---|
| U1 | 数量、格式、大小 | 最多几个？允许哪些格式（大小写是否忽略）？单个大小上限？ | 必须由产品给出，不用样例的“最多 5 份” | 试用确认过一组值，仅作参考 |
| U2 | 不合规时 | 一次选了多个文件、其中有不合规的，是整批拒绝还是只拒绝不合规的？已有列表是否保留？ | 整批拒绝、保留已有列表 | 试用 |
| U3 | 上传过程 | 是否需要表达等待、上传中、失败、成功？ | 本轮只做初始和已选状态 | **规范**（Upload 支持 waiting / progress / success / fail） |
| U4 | 长文件名 | 文件名超长时如何显示？ | 中间省略并保留扩展名 | 试用 |
| U5 | 删除 | 已选文件能否移除？是否需要确认？ | 可移除，不确认 | 试用 |

## S 选择与日期（Select / DatePicker）

| 编号 | 要决定的事 | 问产品的方式 | 推荐默认 | 依据 |
|---|---|---|---|---|
| S1 | 选项来源 | 选项是固定列表还是来自数据字典？有哪些选项？ | 由产品给出；未提供时标注“演示选项” | 判断 |
| S2 | 默认值 | 筛选用下拉默认“全部”还是空？表单下拉默认空还是某个值？ | 筛选默认“全部”，表单默认空 | 试用 |

## G 通用

| 编号 | 要决定的事 | 处理方式 |
|---|---|---|
| G1 | 演示数据 | 需求没给的数据用明确标注的演示数据，不冒充真实业务 |
| G2 | 只读与权限 | 是否存在只读用户、不同角色看到的内容不同？有就逐个列出，没有就写“不区分” |
| G3 | 组件缺口 | 需要的组件不在[组件目录](../components/README.md)中（全局提示、步骤条等仍为缺口；基础弹窗、compact空态、表单单选及只读详情已有部分入口，不代表各家族完整支持，以目录及实际草稿入口为准），在方案卡中列为缺口，由产品和 UI 决定替代方案或延期 |
| G4 | 流程图 | 流程图只用来推导需要哪些页面、状态和跳转，不直接画成界面 |
| G5 | 字体 | 规范字体为 PingFang SC；云端出稿可能临时使用 Noto Sans SC，最终替换和视觉验收在 Mac 上由 UI 处理，见字体检查与替换（内部验证资料未随公开包分发） |

## 维护

试点中出现清单漏掉的问题，或某项问题产品经理普遍认为没必要问，在本文件更新并注明来源试点。新增“试用”依据时写明是哪个业务、哪一天确认的。
