# 设备借用管理演示原型

这是公开测试材料，不是真实业务需求。页面结构、数据和规则均为演示。

列表包含申请标题/状态筛选、发起借用按钮和申请记录表；新增使用500宽单列抽屉，包含申请标题、设备类型、借用日期和用途说明。保留列表空态、已填写、必填错误三种状态。

## 明确规则

- G1：全部数据为演示，未提供真实个人信息。
- G2：本轮交付静态草稿，业务提交与权限校验不实现。
- N1：列表位于行政管理 / 设备借用。
- N2：本轮不增加面包屑返回入口，不影响两个页面的讨论。
- N3：发起借用对应新增抽屉；预览左侧可切换页面/状态，业务按钮为静态示意。
- L1：点击查询才应用条件。
- L2：查询后回第一页。
- L3：重置清空标题，下拉回到全部。
- L4：无结果显示暂无符合条件的借用申请。
- L5：加载中本轮只作文字说明，不新增加载画板。
- L6：查询失败保留条件，本轮不新增失败画板。
- L7：没有申请时使用同一空态，不增加引导按钮。
- L8：演示三条记录，每页十条。
- L9：表格长内容单行省略，完整内容由查看承载。
- L12：待审批可查看/撤回；其他状态只查看。
- L13：撤回前二次确认，草稿中只记录规则，不新增弹窗。
- L14：本轮不做额外行高亮，不影响列表内容。
- L15：提交成功回列表并显示新增记录，仅作规则说明。
- F1：新增申请使用抽屉。
- F2：抽屉宽500，表单单列。
- F3：字段初始为空，不默认选中设备或日期。
- F4：标题、设备、日期必填；标题去除首尾空白。
- F5：标题40字，用途200字，显示计数。
- F6：点击提交统一校验。
- F7：错误在字段下方显示，保留已填内容。
- F8：本演示没有字段联动。
- F9：提交中本轮只作说明，不新增加载画板。
- F10：提交成功关闭抽屉并刷新列表，仅作规则说明。
- F11：提交失败保留输入，本轮不新增失败画板。
- F13：底栏固定，长内容区滚动。
- F14：标题使用短文案，不需要省略。
- F15：右对齐底栏，取消在左、提交在右。
- S1：选项固定为原型中的设备类型与申请状态。
- S2：状态默认全部，设备类型不默认选择。
- S3：本演示下拉单选，不涉及搜索和联动。
- S4：日期格式YYYY-MM-DD，演示不限制日期范围。
